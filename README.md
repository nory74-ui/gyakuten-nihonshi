## 🌟 ゲーム概要

**「その歴史改ざんに……異議あり！」**

現代の中学校で歴史の授業中に居眠りをしていた中学生・**史堂 レイ**と、古文歴史研究部の**古文 ミオ**。  
目を覚ますと、そこは古代の日本！時代ごとに歴史を自らの都合の良い形へ書き換えようと企む権力者たちが立ちはだかる！

各地を歩いて正しい「歴史史料（証拠品）」を集め、法廷で証人のムジュンした証言に突きつけて論破せよ！  
第1話をクリアすると、次の時代（第2話・奈良時代）へタイムスリップ！クリアした時代はタイトル画面の「エピソード選択」からいつでも復習可能！

- **対決相手**: 蘇我 馬子（飛鳥の大豪族）
- **舞台**: 飛鳥宮・難波津（遣隋使）・法隆寺・板蓋宮
- **重要史料**: 冠位十二階の冠、十七条の憲法、遣隋使の国書、法隆寺の図面、蘇我氏系図、中臣鎌足の密書、改新の詔
- **学習要点**: 聖徳太子の政治、小野妹子と遣隋使、法隆寺（飛鳥文化）、中大兄皇子と中臣鎌足の大化の改新（公地公民）

- **対決相手**: 藤原 仲麻呂（奈良の権勢貴族・大納言）
- **舞台**: 平城京 朱雀大路・東大寺 大仏殿建設現場・農村と開墾地・唐招提寺
- **重要史料**: 大宝律令の木簡、和同開珎、租・庸・調の荷札、大仏造立の詔、墾田永年私財法の布告、行基のため池日誌、鑑真の戒本
- **学習要点**: 平城京遷都（長安を手本）、大宝律令（二官八省・国郡里）、和同開珎、重税（租・庸・調・防人）と農民逃亡、墾田永年私財法（743年）と荘園の始まり、聖武天皇の鎮護国家と東大寺大仏建立、行基と鑑真の活躍

## 👥 登場人物

- **史堂 レイ（主人公・弁護士ポジション）**  
  歴史史料から真実を突き止める中学生。法廷では弁護席に立ち、机を叩いて「異議あり！」と矛盾を指摘する。
- **古文 ミオ（助手・パートナーポジション）**  
  古文歴史研究部員。丸メガネとおさげ髪がトレードマーク。常に歴史書を抱え、困った時にはヒントをくれる。
- **蘇我 馬子（第1話・証人）**  
  飛鳥時代の大臣。冠位十二階・十七条の憲法・大化の改新をすべて自らの手柄に改ざんしようと目論む。
- **藤原 仲麻呂（第2話・証人）**  
  奈良時代の大納言。重税で逃げ出した農民を行基の扇動と決めつけ、大仏の資材や開墾地を藤原氏のものにしようと企む。

## 🎯 ゲームシステム

1. **探偵パート（各時代の現地調査）**
   - 時代の名所を巡り、気になる場所を「調べる」、人物と「話す」ことで史料を収集。
   - すべての重要史料（各話7種）を集めて法廷へ挑もう！
2. **法廷パート（尋問・論破バトル）**
   - **ゆさぶる（待った！）**: 証言をゆさぶって証人の動揺（冷や汗）を引き出し、新たな情報を得る。
   - **つきつける（異議あり！）**: 証言のムジュンを見抜き、集めた歴史史料をつきつけて証人を完全論破！
   - つきつけが成功すると、証人が大打撃（白目を剥いて叫ぶダメージ演出）を受け、歴史の真実が解き明かされる！
3. **エピソード選択（復習機能）**
   - 第1話をクリアすると、第2話へのタイムスリップゲートが開く！
   - 一度クリアした時代はタイトル画面の「エピソード選択」からいつでも再挑戦可能。探偵パート・法廷直行のどちらでも学習を復習できます。

## 💻 開発環境・ビルド方法

- **Unityバージョン**: Unity 6 (`6000.3.10f1`)
- **レンダリング**: Universal Render Pipeline (URP 2D)
- **フォント**: 日本語OpenTypeフォント（`JpGameFont.otf`）同梱（WebGL・スマホでも文字化けゼロ）
- **ワンクリック書き出し**:
  - Unityエディタ上部の専用メニュー `逆転日本史` から、WebGL・Mac・Windows・GitHub Pages用（`docs/`）の書き出しが1クリックで行えます。
