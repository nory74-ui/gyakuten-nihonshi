## 🌟 ゲーム概要

**「その歴史改ざんに……異議あり！」**

居眠りをして現代の中学校から西暦604年の飛鳥時代へタイムスリップしてしまった中学生・**史堂 レイ**と、古文歴史研究部の**古文 ミオ**。  
飛鳥の都では、強大な権力を持つ豪族・**蘇我 馬子**が、自らの一族の栄光のために歴史史料をねじ曲げ、都合の良い歴史へ書き換えようとしていた！

飛鳥の町を歩いて正しい「歴史史料（証拠品）」を集め、法廷で馬子のムジュンした証言に突きつけて論破せよ！

## 👥 登場人物

- **史堂 レイ（主人公・弁護士ポジション）**  
  歴史史料から真実を突き止めるのが大好きな中学生。法廷では弁護席に立ち、机を叩いて「異議あり！」と矛盾を指摘する。
- **古文 ミオ（助手・パートナーポジション）**  
  古文歴史研究部員。丸メガネとおさげ髪がトレードマーク。常に歴史書を抱え、困った時にはヒントをくれる。
- **蘇我 馬子（証人・歴史上の重要人物）**  
  飛鳥時代の大豪族。冠位十二階・十七条の憲法・大化の改新など、歴史上の出来事を自分の手柄に改ざんしようと目論む。

## 🎯 ゲームシステム

1. **探偵パート（飛鳥時代の現地調査）**
   - 飛鳥の朝廷・難波津・法隆寺・板蓋宮などの名所を調査。
   - キャラクターと話し、7つの重要歴史史料（冠位十二階の冠、十七条の憲法、遣隋使の国書、法隆寺の図面、蘇我氏系図、中臣鎌足の密書、改新の詔）を収集。
2. **法廷パート（尋問・論破バトル）**
   - **ゆさぶる（待った！）**: 証言をゆさぶって証人の動揺（冷や汗）を引き出し、新たな情報を得る。
   - **つきつける（異議あり！）**: 証言のムジュンを見抜き、集めた歴史史料をつきつけて証人を完全論破！
   - つきつけが成功すると、証人が大打撃（白目を剥いて叫ぶダメージ演出）を受け、歴史の真実が解き明かされる！

## 💻 開発環境・ビルド方法

- **Unityバージョン**: Unity 6 (`6000.3.10f1`)
- **レンダリング**: Universal Render Pipeline (URP 2D)
- **フォント**: 日本語OpenTypeフォント（`JpGameFont.otf`）同梱（WebGL・スマホでも文字化けゼロ）
- **ワンクリック書き出し**:
  - Unityエディタ上部の専用メニュー `逆転日本史` から、WebGL・Mac・Windows・GitHub Pages用（`docs/`）の書き出しが1クリックで行えます。
